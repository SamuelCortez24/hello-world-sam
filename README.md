# Overview

# Hello World – CSE 310

This console application serves as a verification tool to ensure the development environment is correctly configured. It demonstrates basic output execution and validates the compilation workflow.

The purpose of this project was to confirm that my software development tools, including the compiler, IDE, and version control system, are properly set up before continuing with more complex programming assignments.

# Development Environment

This project was developed using the following tools:

- Visual Studio Code
- Git and GitHub for version control
- .NET SDK
- C# programming language

The application is a simple console program written in C#. It prints the text **"Hello World"** to the terminal to confirm that the development environment is functioning correctly.
