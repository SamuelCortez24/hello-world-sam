# Overview

This console application serves as a verification tool to ensure the development environment is correctly configured. It demonstrates basic output execution and validates the compilation workflow.

The purpose of this project was to validate the software toolchain and version control integration before moving on to complex logic.

[Software Demo Video](http://youtube.link.goes.here)

# Development Environment

Developed using Visual Studio Code with Git for version control. Written in C# to leverage its strong typing features.
