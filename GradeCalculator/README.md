# Student Grade Calculator

## Description
This is a C# console application that allows users to enter multiple grades and calculates the average and final letter grade.

## How to Run
1. Install .NET SDK
2. Open terminal
3. Run:
   dotnet run

## Features
- Input multiple grades
- Calculates average
- Displays letter grade
